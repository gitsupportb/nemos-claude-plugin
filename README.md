# Némos for Claude

Némos is a private library for saved notes, links, screenshots, recordings, and research. This plugin lets Claude search and read your own Némos items through a remote MCP connector. Connect with Apple when prompted; the plugin does not contain a password or API key. Its skill helps Claude choose search, item reading, related items, recent items, or a context pack based on your question and cite the original sources.

The connector is read-only. It cannot create, edit, delete, or share Némos items. Each person authorizes access to their own library. See the [Némos MCP guide](https://nemosapp.com/mcp/) for setup, [privacy policy](https://nemosapp.com/privacy/) for data handling, and [FAQ](https://nemosapp.com/faq/) for support.
